Herencia Multiple

La herencia múltiple en Python es una característica del lenguaje que permite a una clase heredar de más de una clase base. Esto significa que una clase hija puede incorporar atributos y métodos de múltiples clases padres. 


class ClaseBase1:
    # Métodos y atributos de ClaseBase1
    pass

class ClaseBase2:
    # Métodos y atributos de ClaseBase2
    pass

class ClaseHija(ClaseBase1, ClaseBase2):
    # Métodos y atributos de ClaseHija
    pass
      
      
class Persona:
    def __init__(self, nombre):
        self.nombre = nombre

    def mostrar_nombre(self):
        print(f"Nombre: {self.nombre}")

class Trabajador:
    def __init__(self, salario):
        self.salario = salario

    def mostrar_salario(self):
        print(f"Salario: {self.salario}")

# Clase que hereda de ambas
class Gerente(Persona, Trabajador):
    def __init__(self, nombre, salario, departamento):
        Persona.__init__(self, nombre)
        Trabajador.__init__(self, salario)
        self.departamento = departamento

    def mostrar_departamento(self):
        print(f"Departamento: {self.departamento}")

# Uso
gerente = Gerente("Ana", 50000, "Ventas")
gerente.mostrar_nombre()        
# Nombre: Ana
gerente.mostrar_salario()       
# Salario: 50000
gerente.mostrar_departamento()  
# Departamento: Ventas

MRO

El Method Resolution Order (MRO) (Orden de Resolución de Métodos) es el mecanismo que utiliza Python para determinar en qué orden buscar métodos o atributos en una jerarquía de clases, especialmente en el caso de herencia múltiple. Esto asegura que se eviten ambigüedades y conflictos al acceder a métodos o atributos en las clases.

Cómo funcona el MRO

Python utiliza el algoritmo de C3 Linearization para calcular el MRO. Este algoritmo respeta tres principios clave:

  1. Consistencia en la jerarquía: El MRO respeta el orden en el que las clases están declaradas en la lista de herencia.
  2. Prioridad a la clase actual: Primero busca en la clase actual, luego en las clases base.
  3. Evita duplicaciones y respeta el orden: Si una clase aparece varias veces en la jerarquía, solo se considera la primera aparición según el MRO.

Cómo ver el MRO en Python

Puedes visualizar el MRO de una clase utilizando:

  • El método .mro()
  • La función help()

class A:
    def metodo(self):
        print("Método en A")

class B(A):
    def metodo(self):
        print("Método en B")

class C(A):
    def metodo(self):
        print("Método en C")

class D(B, C):
    pass

print(D.mro())

# Salida: 
"""
[
class '__main__.D', 
class '__main__.B', 
class '__main__.C', 
class '__main__.A', 
class 'object'
]
"""
help(D)  # También muestra el MRO

Ejemplo práctico

        
class A:
    def metodo(self):
        print("Método de A")

class B(A):
    def metodo(self):
        print("Método de B")

class C(A):
    def metodo(self):
        print("Método de C")

class D(B, C):
    pass

obj = D()
obj.metodo()  # Salida: "Método de B"
