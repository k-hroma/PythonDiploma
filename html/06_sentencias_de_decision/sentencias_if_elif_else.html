Sentencias de decisión

Las sentencias de decisión permiten controlar el flujo de un programa
Las estructuras que se pueden utilizar son:

  • if:
    • permite ejecutar un bloque de código si la condición a evaluar es verdadera.
    una condición es una expresión que evalúa a True/False (valores booleanos).
  • else
    • permite ejecutar un bloque de código cuando la condición del if es falsa.
  • elif
    • se utiliza cuando necesitamos verificar múltiples condiciones, una tras otra.

Operador ternario: es una forma compacta de agregar una condición
ej:
color = "rojo"
resultado = "si es rojo" if color == "rojo" else "no es rojo"
print(resultado)
Diagrama de flujo
Es una representación gráfica de los pasos a ejecutar para lograr un resultado específico.
* un óvalo: representa inicio o fin de un programa
* un rectáncgulo: muestra instrucciones o acciones a ejecutar
* un rombo: indica decisiones con múltiples flujos dependiendo de si la respuesta es verdadera o falsa
* una flecha: dirigen el flujo y muestran la dirección en la que se mueve la secuencia de acciones
