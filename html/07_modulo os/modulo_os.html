Módulo Os

El módulo os en Python es una librería que permite interactuar con el sistema operativo, realizando operaciones que dependen de él.
Entre las cosas que se pueden hacer con este módulo se encuentran:

  • Crear, eliminar y mover archivos y directorios
  • Listar el contenido de una carpeta
  • Conocer información sobre un proceso
  • Finalizar un proceso
  • Trabajar con rutas de archivos y directorios

El módulo os es una de las librerías más utilizadas en Python. Su documentación se subtitula «Interfaces diversas del sistema operativo».
Algunas cosas a tener en cuenta sobre el módulo os son:
  • El módulo os.path es el adecuado para el sistema operativo en el que Python está funcionando.
  • El módulo os también permite acceder a las extensiones propias de un sistema operativo, aunque esto puede comprometer la portabilidad.
  • En plataformas como Android, iOS y WebAssembly, no están disponibles o funcionan de forma diferente grandes partes del módulo os.
