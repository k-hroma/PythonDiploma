Módulo sys

El módulo sys en Python forma parte de la biblioteca estándar y proporciona funciones y variables para interactuar directamente con el intérprete de Python y su entorno. Es especialmente útil para acceder a configuraciones del sistema y manejar aspectos relacionados con el flujo de ejecución del programa.

    Algunas características principales
  1. Acceso a argumentos de líneas de comando:
    • La lista sys.argv contiene los argumentos pasados al programa desde la línea de comandos. El primer elemento (sys.argv[0]) es el nombre del script.
  2. Control del flujo de entrada y salida:
    • Puedes redirigir el flujo de entrada estándar (sys.stdin), salida estándar (sys.stdout) y error estándar (sys.stderr).
  3. Acceso a información del intérprete:
    • sys.version: Versión de Python instalada.
    • sys.platform: Plataforma en la que se está ejecutando Python.
    • sys.executable: Ruta del intérprete de Python.
  4. Gestión de excepciones:
    • sys.exc_info(): Proporciona información sobre la excepción más reciente capturada.
  5. Finalización del programa:
    • sys.exit([código]): Detiene el programa y opcionalmente devuelve un código de salida (por defecto, 0 para indicar éxito).
  6. Modificación de la ruta de búsqueda de módulos:
    • sys.path: Una lista de rutas donde Python busca los módulos para importar.
