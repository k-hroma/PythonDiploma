LISTS

Una lista en Python es un tipo de dato que permite almacenar múltiples elementos en un solo contenedor. Es una estructura de datos ordenada, mutable (modificable) y puede contener elementos de diferentes tipos, como números, cadenas, otros objetos, e incluso otras listas.

    Características principales


  • Ordenada: Los elementos mantienen el orden en el que se agregan.
  • Mutable: Puedes agregar, modificar o eliminar elementos.
  • Heterogénea: Puede contener elementos de diferentes tipos.
  • Índices: Cada elemento tiene un índice, empezando desde 0.

TUPLES

Una tupla en Python es una colección inmutable de elementos, lo que significa que una vez creada, no se pueden modificar, añadir ni eliminar elementos. Se usa para almacenar múltiples elementos en una sola variable y se define con paréntesis ().

    Características principales


  • Ordenada: Los elementos mantienen el orden en el que se agregan.
  • Inmutable: Una vez creadas, no se pueden modificar. Esto significa que no puedes agregar, eliminar ni cambiar los elementos de una tupla.
  • Heterogénea: Puede contener elementos de diferentes tipos.
  • Índices: Cada elemento tiene un índice, empezando desde 0.
  • Aceptan duplicados: Una tupla puede contener elementos repetidos.
  • Soportan operaciones comunes: Puedes usar operadores como concatenación (+), repetición (*) y verificación de pertenencia (in).
  • Se pueden usar como claves en diccionarios: Debido a que son inmutables, las tuplas son hashables y pueden servir como claves en un diccionario, a diferencia de las listas.
  • Pueden desempaquetarse: asignar los elementos de una tupla directamente a variables individuales. Esta característica es muy útil en Python y se aplica tanto a tuplas como a otros contenedores iterables.

SETS

Un set en Python es un tipo de dato incorporado que representa una colección desordenada y sin elementos duplicados. Es útil cuando necesitas almacenar elementos únicos y realizar operaciones de conjuntos como uniones, intersecciones o diferencias.

    Características principales


  • No ordenado: Los elementos en un set no tienen un orden fijo. No puedes acceder a ellos mediante índices como en una lista o una tupla.
  • Mutable, pero con elementos inmutables: Puedes agregar o eliminar elementos de un set, pero los elementos dentro del set deben ser de tipos inmutables (como números, cadenas o tuplas). No puedes usar listas o diccionarios como elementos de un set.
  • Heterogénea: Puede contener elementos de diferentes tipos.
  • No aceptan duplicados: Un set no puede contener duplicados. Al convertir otras colecciones (listas, tuplas, etc.) a sets, automáticamente se eliminan los elementos duplicados.
  • Operaciones matemáticas: Los sets soportan operaciones como unión, intersección, diferencia y diferencia simétrica, similares a los conceptos en teoría de conjuntos.
  • Pueden desempaquetarse: los sets pueden desempaquetarse utilizando el operador de desempaquetado (*). Este operador extrae todos los elementos del set y los convierte en elementos separados que se pueden usar en otras estructuras, como listas, tuplas, o como argumentos en funciones. Sin embargo, dado que los sets no tienen un orden definido, el orden en el que se desempaquetan los elementos es arbitrario.

DICTIONARIES

Un diccionario en Python es un tipo de dato que permite almacenar colecciones de pares clave-valor. Es una estructura muy útil cuando se necesita asociar un conjunto de valores con un conjunto de claves o llaves que sirven como índices únicos.

    Características principales


  • Claves y valores:
    • Claves únicas: Cada clave en un diccionario debe ser única. Si se asigna un nuevo valor a una clave existente, sobrescribirá el valor anterior.
    • Cualquier tipo inmutable como clave: Las claves deben ser de tipos inmutables, como cadenas, números o tuplas (siempre que las tuplas solo contengan elementos inmutables).
    • Valores de cualquier tipo: Los valores pueden ser de cualquier tipo, incluidos otros diccionarios, listas, o incluso funciones.
  • Mutables: Los diccionarios son mutables, lo que significa que puedes agregar, modificar o eliminar elementos después de haberlos creado.
  • Ordenados: Desde Python 3.7, los diccionarios conservan el orden de inserción de los elementos. Antes de eso, no garantizaban un orden específico.

Comprensión de listas

La comprensión de listas en Python es una forma concisa y elegante de crear listas nuevas a partir de iterables existentes, como listas, tuplas, conjuntos o rangos. Permite escribir bucles y condiciones en una sola línea de código, lo que puede hacer que el código sea más legible y eficiente.

    Sintaxis básica:


  • [nueva_expr for elemento in iterable if condicion]
    1. nueva_expr: La expresión que define qué se incluirá en la nueva lista.
    2. for elemento in iterable: Itera sobre el iterable existente.
    3. if condicion: (opcional) Filtra los elementos según una condición.
    Ventajas: Sintaxis más compacta y legible. Mejor rendimiento en comparación con bucles tradicionales.
    Cuándo evitarlo: Cuando la lógica es compleja, ya que puede reducir la legibilidad del código. En esos casos, un bucle for convencional es preferible.
