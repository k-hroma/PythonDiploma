Detalles de una cadena

  • Los caracteres de una cadena están indexados de una manera secuencial Por lo tanto se puede acceder a cada caracter indicando el índice del caracter
  • Una vez que se crea una cadena, los caracteres dentro de ella no pueden ser modificados: hay que crear una nueva cadena
  • Hay caracteres especiales
  • Concatenación de cadenas:
    • uso del operador +
    • uso del método join = "".join([cadena1, cadena2, etc])
  • Formateo de cadenas: diferentes maneras de formatear cadenas (concatenar texto, variables, etc)
    • f-string: es la más sencilla y legible
    • método format: permite construir cadenas muy complejas
  • Métodos de cadenas
    • .upper()
    • .lower()
    • .strip()
    • .len()(funciona con distintos tipos: listas, cadenas, dicc, etc)
  • Subcadenas
    • Sclicing: indican los índices de inicio y final del segmento de la cadena que se quiere extraer
    • Buscar subcadenas = cadena.find("subcadena") = devuelve el indice de la primera aparicion de la subcadena
    • Reemplazar subcadenas = cadena.replace("subcadena", "subcadena") = reemplaza una subcadena por otra dentrto de una cadena ppal
    • Extraer subcadenas por separadores (.split()) = permite dividir una cadena en una lista de subcadenas basadas en un caracter separador
