Funciones en Python

Las funciones son bloques de código para realizar una tares en particular.
Se pueden reutilizar en diferentes pasrtes de un proframa.
Sirven para organizar el código, hacerlo más legible, evitar redundancia y facilitar el mantenimiento.

    Características principales

  1. Reutilización de código: Puedes escribir el código una vez y usarlo varias veces.
  2. Modularidad: Dividen el programa en partes más manejables.
  3. Legibilidad: Facilitan la comprensión del propósito del código.
  4. Facilidad de depuración: Separar funcionalidades específicas en funciones simplifica la identificación de errores.
  5. Parametrización: Las funciones pueden ser diseñadas para aceptar parámetros, lo que hace más flexible los programas.

    Sintaxis básica de definición de una función

  • Define de la función (verbo o acción): def nombre_funcion(parámetros)
  • Defini el cuerpo de la función: es el código que se ejecuta cuando se manda a llamar a la función
  • Se llama a la función pasándole los argumentos

    Alcance de las variables

  • Global: Variables definidas en el nivel más alto del módulo (fuera de cualquier función o clase). Pueden ser accedidas desde cualquier lugar del archivo (a menos que estén ocultas por una variable local con el mismo nombre).
  • Local: Variables definidas dentro de una función o bloque.
  • No local (Enclosing): Variables en funciones anidadas, en el ámbito de una función externa pero no global. Si tienes funciones anidadas, la función interna puede acceder a las variables definidas en la función que la contiene, pero no puede modificarlas directamente sin usar la palabra clave nonlocal.

    Argumentos variables

    En Python, los argumentos variables permiten que una función acepte un número arbitrario de elementos.
    Hay dos tipos principales:

  • Argumentos posicionales variables *args: permite pasar argumentos posicionales a una función, recibiendolos como una tupla dentro de la función.
  • Argumentos con palabra clave **kwargs: permite pasar argumentos de forma (clave-valor)

    Funciones recursivas

    Las funciones recursivas en Python (y en general en programación) son funciones que se llaman a sí mismas, directa o indirectamente, para resolver un problema dividiéndolo en subproblemas más pequeños y manejables.
    Debe avanzar hacia un caso base, de lo contrario caería en un ciclo infinito.

    Características principales

  • Caso base: La función debe tener una condición que detenga la recursión (el caso base). Esto evita que la función se llame indefinidamente y cause un desbordamiento de pila (stack overflow).
  • Caso recursivo: Es la parte de la función que llama a sí misma con un argumento modificado, acercándose al caso base.

              def funcion_recursiva(parametro):
# Caso base
if condicion_para_detener: # ej: si n==1, entonces 
    return resultado       # devuelve n

# Caso recursivo
else:                      # si n!= 1 
    return funcion_recursiva(nuevo_parametro) # entonces se llama a si misma con un parámetro distinto (n-1)
