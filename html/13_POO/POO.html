Introducción

La herencia en Python es un principio fundamental de la Programación Orientada a Objetos (POO) que permite a una clase (llamada clase hija o subclase) heredar propiedades y comportamientos (atributos y métodos) de otra clase (llamada clase padre o superclase). Esto permite reutilizar el código, extender la funcionalidad y organizar mejor las relaciones entre clases.

Características principales de la herencia en Python:

  1. Reutilización de código: La subclase puede usar los métodos y atributos definidos en la superclase sin necesidad de volver a definirlos.
  2. Extensibilidad: Puedes agregar nuevos métodos y atributos en la subclase o sobrescribir los heredados para personalizarlos.
  3. Jerarquía: Las clases pueden formar jerarquías donde una subclase puede heredar de otra subclase, creando niveles de herencia.

Sintáxis básica

        
class SuperClase:
    def __init__(self, nombre):
        self.nombre = nombre

    def saludar(self):
        print(f"Hola, soy {self.nombre}")

class SubClase(SuperClase):
    def __init__(self, nombre, edad):
        # Llamamos al constructor de la superclase
        super().__init__(nombre)
        self.edad = edad

    def presentar(self):
        print(f"Soy {self.nombre} y tengo {self.edad} años")

# Crear un objeto de la subclase
persona = SubClase("Ana", 25)

# Llamar métodos heredados y propios
persona.saludar()       # Salida: Hola, soy Ana
persona.presentar()     # Salida: Soy Ana y tengo 25 años

Conceptos avanzados relacionados con la herencia:

  1. Sobrescritura de métodos: Una subclase puede redefinir un método de la superclase si necesita un comportamiento diferente.

  3. Herencia múltiple: Una clase puede heredar de varias superclases en Python.

  4. Tipos de relaciones
    • Herencia simple: Una clase hereda de una única superclase.
    • Herencia múltiple: Una clase hereda de dos o más superclases.
    • Herencia jerárquica: Varias clases heredan de una misma superclase.
  5. Polimorfismo: El polimorfismo en Python, como en otros lenguajes de programación orientada a objetos, es la capacidad de un objeto o función de tomar múltiples formas. En términos simples, el polimorfismo permite que un mismo método o función pueda operar sobre diferentes tipos de objetos o clases, y comportarse de manera específica dependiendo del contexto.
    6. 
class Animal:
    def hacer_sonido(self):
        print("El animal hace un sonido")

class Perro(Animal):
    def hacer_sonido(self):
        print("El perro ladra")

class Gato(Animal):
    def hacer_sonido(self):
        print("El gato maúlla")

# Uso del polimorfismo
animales = [Perro(), Gato(), Animal()]

for animal in animales:
    animal.hacer_sonido()
# Salida:
# El perro ladra
# El gato maúlla
# El animal hace un sonido
        
    

# Polimorfismo
class Animal:
    def hacer_sonido(self):
        print('Hago un pitido')

class Perro(Animal):
    # pass
    def hacer_sonido(self):
        print('Puedo ladrar')

class Gato(Animal):
    def hacer_sonido(self):
        print('Puedo maullar')

# Funcion polimorfica
def hacer_sonido_animal(animal):  # duck typing
    animal.hacer_sonido()

print('*** Ejemplo Polimorfismo ***')
print('Clase Padre Animal: ')
animal1 = Animal()
hacer_sonido_animal(animal1)
# Definimos un objeto de la clase Perro
print('\nClase Hija Perro: ')
perro1 = Perro()
hacer_sonido_animal(perro1)
# Definimos un objeto de la clase Gato
print('\nClase Hija Gato: ')
gato1 = Gato()
hacer_sonido_animal(gato1)
