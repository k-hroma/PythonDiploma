Colecciones en python

Una colección es un conjunto de datos, por eso tambien se les conoce como Estructura de datos. En Python, una estructura de datos es una forma organizada de almacenar y manipular datos de manera eficiente, dependiendo del caso de uso. Permiten gestionar grandes volúmenes de datos y realizar operaciones como búsqueda, inserción, eliminación y ordenamiento de forma más fácil y eficiente. Python ofrece una variedad de estructuras de datos integradas y herramientas avanzadas para personalizarlas.

Principales estructuras de datos en Python:

  • Listas (list):

    • Qué son:

      • Colección ordenada de elementos mutables que pueden ser de cualquier tipo.

    • Características:

      • Permiten duplicados
      • Acceso por indice
      • Son dinámicas
      • Pueden anidarse
      • Son iterables (ciclo for):
        • valores = [1, "dos", True]
        for valor in valores:
        ____print(valor)

    • Métodos:

      • list.append:(valor)
      • list.extend: (lista)
      • list.insert: (indice, valor)
      • list.remove(valor)
      • list.pop(indice)
      • del list[indice]
      • sub_list=list[1:3]
      • valor = list[0].split()[]

  • Tuplas (tuple):

    • Qué son:

      • Colección ordenada de elementos, pero inmutables.

    • Características:

      • Una vez creadas, no se pueden modificar.
      • Útiles para datos que no deben cambiar.
      • Acceso por indice
      • Pueden iterarse
      • Pueden anidarse
      • Pueden desempaquetarse:
        • El desempaquetado de una tupla es una técnica en Python que permite asignar los valores de una tupla (o cualquier iterable) directamente a múltiples variables en una sola línea de código. Esto se logra al igualar la tupla a las variables correspondientes.

  • Las listas y las tuplas pueden combinarse:

    • list = [(tuple1), (tuple2), (tuple3)]
      # tuple1 = (int1, str1, float1)
      # tuple2 = (int2, str2, float2)
      # tuple3 = (int3, str3, float3)

    • pueden iterarse para hacer el unpacking:
      for valor in list:
      ____id, descripcion, precio = valor

  • Sets (set):

    • Qué son:

      • Colección desordenada de elementos únicos

    • Características:

      • No permiten valores duplicados
      • No tienen indice
      • Son iterables

    • Métodos:

      • set.add(valor)
      • set.remove(valor) - lanza error si no existe
      • set.discard(valor) - no lanza error si no existe
      • set.pop() - elimina y devuelve un elemento aleatorio del conjunto
      • set.clear() - elimina todos los elementos del set
      • valor in set = devuelve True/False
      • len(set)

    • Operaciones:

      • set.union(*otros) - devuelve un nuevo set con la union de dos o mas conjuntos
      • set.intersection(*otros) - devuelve un nuevo conjunto con los elementos comunes
      • set.difference(*otros) - devuelve un nuevo conjunto con los elementos que están en el conjunto original pero no en los otros.
      • set.symmetric_difference(*otro) - devuelve un nuevo conjunto con los elementos que están en uno u otro conjunto, pero no en ambos.
      • set.issubset(*otro) - Devuelve True si el conjunto actual es un subconjunto del otro.
      • set.isdisjoint(otro) - Devuelve True si los dos conjuntos no tienen elementos en común.

  • Diccionarios (dict):

    • Un diccionario en Python es una estructura de datos ordenada que almacena pares clave-valor. Es muy útil para organizar y acceder a datos asociados. Las claves deben ser únicas e inmutables (por ejemplo, cadenas, números o tuplas), mientras que los valores pueden ser de cualquier tipo.

    sintaxis: dict = {clave1: valor1, clave2:valor2}

    • Características principales:

      • Colección desordenada: Los elementos no tienen un orden específico.
      • Claves únicas: No pueden repetirse. Si se intenta asignar un valor a una clave existente, este será sobrescrito.
      • Acceso rápido: Los valores se acceden directamente mediante su clave.
      • Mutables: Puedes modificar, agregar o eliminar elementos después de haberlo creado.

    • Métodos Principales

      • Crear un dict:
        • * usando claves: mi_dicc = {"key": "valor", "key2": "valor2"}
        * usando el constructor: mi_dicc = dict(key1=valor1, key2=valor2)
      • Acceder a sus elementos:
        • * usando claves: print(mi_dicc["key"])
        * usando el método .get(): mi_dicc.get("key")
      • Modificar un diccionario
        • * agregar o actualizar
        * eliminar
        * iterar (bucle for (solo en clave, solo en valor o en clave, valor(dict.items())))

    • Métodos útiles

      • dict.keys: devuelve todas las claves
      • list(dict.items()//dict.values()//dict.keys())
      • dict.values(): devuelve todos los valores
      • dict.items: devuelve pares clave-valor como tuplas
      • dict.pop(clave): elimina la clave dada y devuelve su valor
      • dict.clear: vacía el dicc
      • dict.update(dict2): agrega o actualiza elementos desde otro diccionario

  • Comprension de listas

    • La comprensión de listas en Python es una forma concisa y eficiente de crear listas nuevas a partir de iterables existentes, como listas, tuplas o rangos, aplicando una expresión opcionalmente seguida de condiciones. Es muy útil para reducir código y mejorar la legibilidad.

      Sintaxis básica:

      [expresión for elemento in iterable if condición]

      1. expresión: Lo que se incluirá en la nueva lista(puede ser el elemnto tal cual o una operacion sobre él.)
      2. for elemento in iterable: Itera sobre un iterable, como una lista, rango o conjunto.
      3. if condición (opcional): Filtra elementos que cumplan una condición específica.

  • Desempaquetado de estructura de datos

    • En Python, muchas estructuras de datos pueden desempaquetarse utilizando la sintaxis de desempaquetado (* o **) o asignación múltiple.
    Estas estructuras incluyen:

    1. Listas y tuplas

      * Puedes desempaquetar valores directamente en variables:
      
lista = [1, 2, 3]
a, b, c = lista  # a=1, b=2, c=3
              
      
tupla = (4, 5, 6)
x, y, z = tupla # x=4, y=5, z=6
      * También puedes usar * para capturar valores restantes:
      
lista = [1, 2, 3, 4, 5]
a, *b, c = lista  # a=1, b=[2, 3, 4], c=5

    2. Sets:

      * Aunque los conjuntos no son ordenados, puedes desempaquetarlos:
      
conjunto = {7, 8, 9}
a, b, c = conjunto  # El orden no está garantizado

    3. Diccionarios

      * Claves por defecto:
      
diccionario = {'x': 10, 'y': 20, 'z': 30}
a, b, c = diccionario  # a='x', b='y', c='z'
      * Valores usando .values():
      
valores = diccionario.values()
a, b, c = valores  # a=10, b=20, c=30
      * Claves y valores como tuplas con .items():
      
items = diccionario.items()
for clave, valor in items:
    print(clave, valor)

    4. Strings

      * Las cadenas se pueden desempaquetar carácter por carácter:
      
cadena = "abc"
a, b, c = cadena  # a='a', b='b', c='c'

    5. Generadores y Iteradores

      * Si defines un método __iter__ o __getitem__, puedes hacer que tu clase soporte desempaquetado:
      
              class MiClase:
              def __init__(self):
              self.datos = [1, 2, 3]

              def __iter__(self):
              return iter(self.datos)
              obj = MiClase()
              a, b, c = obj # a=1, b=2, c=3

    6. Desempaquetado Extendido

      * Usando * para listas y ** para diccionarios:

      # Para listas

      
lista1 = [1, 2, 3]
lista2 = [4, 5]
nueva_lista = [*lista1, *lista2]  # [1, 2, 3, 4, 5]

      # Para diccionarios

      
dic1 = {'a': 1, 'b': 2}
dic2 = {'c': 3}
nuevo_dic = {**dic1, **dic2}  # {'a': 1, 'b': 2, 'c': 3}
