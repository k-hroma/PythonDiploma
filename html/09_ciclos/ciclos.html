Ciclos

Los ciclos en Python son estructuras de control que permiten ejecutar un bloque de código repetidamente mientras se cumple una condición o hasta recorrer una secuencia de elementos. Son fundamentales para tareas repetitivas, como procesar listas, calcular valores o realizar operaciones iterativas.

Tipos de ciclos en Python

  1. Bucle While:
    * Ejecuta un bloque de código mientras se cumple una condición(mientras sea verdadera).
    * Es útil cuando no sabes cuántas iteraciones necesitas de antemano.
    Diagrama de flujo de un bucle while:
  2. Bucle For:
    * Se utiliza para recorrer elementos de una secuencia (como listas, cadenas, tuplas, diccionarios, etc.)
    * Ejecuta un bloque de código un número definido de veces.

Sentencias "Break" y "Continue"

En Python, las sentencias break y continue son comandos que se utilizan para interrumpir ciclos en un bucle:

  • Break: detiene la ejecucion del bucle y termina todas las iteraciones siguientes.
  • Continue: detiene la iteración actual y salta a la siguiente iteración.
