Variables y comentarios

En python cada vez que creamos una variable y le asignamos un valor estamos reservando un espacio en la memoria RAM.
Hay dos tipos de memoria:

  1. STACK = se utiliza para almacenar informacion relacionda con las f(x) activas como:
    • variables locales de las funciones
    • direcciones de retorno
  2. HEAP = se utiliza para almacenar objetos y datos dinámicos
    • listas
    • diccionarios
    • cualquier dato mutable
