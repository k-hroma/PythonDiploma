Tipos de datos

  • python es un lenguaje de tipado dinámico
  • no hay necesidad de indicar el tipo de la variable
  • las variables que se pueden almacenar son de distintos tipos:
    • Números = int
    • Números con punto flotante = float
    • Cadenas de txt = str
    • Booleanos (almacena un valor lógico de verdaero o falso// se usan para controlar el flujo de un programa) = True/False
    • None = ausencia de valor
