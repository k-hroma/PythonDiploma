Operadores

Los operadores son simbolos especiales que estan diseñados para realizar operaciones especifícas. Hay distintos tipos:

  • Operadores aritméticos: permiten realizar cálculos matemáticos
    • suma
    • resta
    • multiplicación
    • division
    • division entera
    • módulo
    • exponente
  • Operadores de asignación: asignan valores a variables (caracter "=")
    * puede ser simple (var1 = valor1)
    * puede ser multiple (variable1, variable2 = valor1, valor2)
    * puede ser encadenada (var1, var2, var3 = 10)
    * puede ser compuesto (var1+= var2)
  • Operadores de comparación (relacionales): comparan un valor con otro(el resultado siempre es un valor booleano [True/False]):
    el resultado de la comparación se puede utilizar para tomar decisiones sobre el flujo del programa.
    los operadores relacionales se pueden combinar con los operadores lógicos AND, OR y NOT
    * op. de igualdad (==)
    * op. distinto (!=)
    * op. menor que (<) // op.menor o igual que (<=)
    * op. mayor que (>) // op.mayor o igual que (>=)
  • Operadores lógicos: se utilizan para combinar expresiones condicionales lógicas y con valores booleanos
    * and (devuelve True si ambos operadores son verdaderos) * or (devuelve True si uno de los operadores es verdaderos) * not (invierte el valor del operador. Es un operador unario:)
    En Python, el operador lógico not se utiliza para invertir el valor de un booleano o negar una condición:
    Invierte True por False y False por True
    * Se puede usar en un condicional "if" para invertir el funcionamiento del código
    * Se puede usar con cualquier objeto, ya que cualquier objeto es verdadero o falso
    * Por ejemplo, si se quiere que un programa solo tome valores que estén fuera de un cierto rango, se puede usar el operador not para invertir el valor del booleano.
  • Operadores de identidad: se utilizan para compara si dos variables son el mismo objeto
  • Operadores de membresía: se utilizan para comprobar si una secuencia se presenta en un objeto
  • Precedencia de operadores: determina el orden en el que se evalúan las operaciones en una expresión
