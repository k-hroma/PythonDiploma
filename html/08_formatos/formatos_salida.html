Método pprint

El método pprint en Python viene del módulo pprint (abreviatura de pretty-print) y se utiliza para imprimir estructuras de datos (como listas, diccionarios, tuplas, etc.) de forma más legible y organizada. Es especialmente útil cuando trabajas con datos complejos o muy anidados.
Características principales:(ver formato2.py)

  • Formato legible: Muestra los datos con saltos de línea, sangrías y espaciado para que sean fáciles de leer.
  • Ideal para estructuras anidadas: Ayuda a visualizar diccionarios o listas con múltiples niveles de profundidad.
  • Configuración opcional: Puedes personalizar el ancho de impresión, la profundidad máxima o incluso formatear objetos.
