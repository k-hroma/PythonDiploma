Funciones en Python

Las funciones en Python son bloques de código que realizan una tarea específica y pueden ser reutilizados en diferentes partes de un programa. Sirven para organizar el código, hacerlo más legible, evitar redundancia y facilitar el mantenimiento.

Características de las funciones en Python:

  1. Reutilización de código: Puedes escribir el código una vez y usarlo varias veces.
  2. Modularidad: Dividen el programa en partes más manejables.
  3. Legibilidad: Facilitan la comprensión del propósito del código.
  4. Facilidad de depuración: Separar funcionalidades específicas en funciones simplifica la identificación de errores.
  5. Parametrización: Las funciones pueden ser diseñadas para aceptar parámetros, lo que hace más flexible los programas.

Definición de funciones

En Python, las funciones se definen con la palabra clave def, seguida del nombre de la función, paréntesis y dos puntos. El bloque de código dentro de la función está indentado.

Sintaxis básica: 


        def nombre_funcion(parametros):
        """Docstring opcional: describe lo que hace la función."""
            # Bloque de código
            return resultado  
            # Opcional: Devuelve un valor

Ejemplo sencillo:


        def saludar(nombre):
        """Esta función imprime un saludo."""
            print(f"Hola, {nombre}!")
        # Llamar a la función
        saludar("Mundo")  # Salida: Hola, Mundo!

Partes de una función:

  1. Nombre de la función: Debe ser descriptivo y seguir las reglas de nombres en Python (letras, números, guion bajo, pero no empezar con un número).
  2. Parámetros (opcional): Variables que se pasan a la función para personalizar su comportamiento.
    3. 
        def sumar(a, b):
            return a + b

        print(sumar(3, 5))  # Salida: 8
  3. Cuerpo: Contiene las instrucciones que se ejecutan cuando se llama a la función.
  4. Valor de retorno(return(opcional)): Las funciones pueden devolver un valor usando return.
    5. 
        def cuadrado(n):
            return n ** 2

        resultado = cuadrado(4)
        print(resultado)  # Salida: 16

Tipos de funciones en Python

  1. Funciones definidas por el usuario: Escritas por el programador para tareas específicas.
    2. 
        def resta(a, b):
            return a - b
  2. Funciones integradas: Funciones predefinidas de Python, como print(), len(), sum(), etc.
    3. 
        print(len("Hola"))  
        # Salida: 4
  3. Funciones lambda(anónimas): Son funciones pequeñas y rápidas que se definen en una sola línea. 
    4. 
        cuadrado = lambda x: x ** 2
        print(cuadrado(3))  
        # Salida: 9

    return resultado_suma # Devuelve el resultado de la suma

Explicación del código

  1. La función sumar toma dos argumentos, a y b.
  2. Calcula la suma y almacena el resultado en la variable resultado.
  3. Con return resultado_suma, se envía el valor de la suma al lugar donde se llamó la función.
  4. Ese valor se puede guardar en una variable (resultado_funcion) o usar directamente.

Módulos en Python

Un módulo en Python es un archivo que contiene código Python (como funciones, clases o variables) que se puede usar en otros programas o scripts. Los módulos permiten organizar y reutilizar el código, facilitando el mantenimiento y la legibilidad.

Tipos de módulos

  1. Módulos estándar: Vienen incluidos con Python. Ejemplo: math, os, random, etc.
  2. Módulos de terceros: Debes instalarlos usando herramientas como pip. Ejemplo: numpy, pandas, etc
  3. Módulos personalizados: Creados por ti o por otros programadores para un propósito específico.

Alcance de variables en Python

El alcance de las variables en Python se refiere a las reglas que determinan desde dónde una variable puede ser accedida o utilizada en un programa. Esto depende de dónde se declaró la variable y si pertenece a un contexto global o local.
Python sigue el principio LEGB, que representa el orden en el que busca variables:

Tipos de alcance

  1. Local: Variables definidas dentro de una función o bloque.
    2. 
def mi_funcion():
    x = 10  # Alcance local
print(x)

mi_funcion()  # 10
# print(x)  # Error: x no está definida fuera de la función
  2. Global: Variables definidas en el nivel más alto del módulo (fuera de cualquier función o clase). Pueden ser accedidas desde cualquier lugar del archivo (a menos que estén ocultas por una variable local con el mismo nombre).
    3. 
x = 10  # Alcance global
def mi_funcion():
    print(x)

mi_funcion()  # 10
print(x, "Desde fuera de la f(x)")

contador_global = 0

    # Declaramos una variable local
    contador_local = 0

    global contador_global
    # incrementamos la variable global
    contador_global += 1

    # Imprimimos ambos contadores
    print(f'Contador local: {contador_local}')

Funciones recursivas

Las funciones recursivas en Python (y en general en programación) son funciones que se llaman a sí mismas, directa o indirectamente, para resolver un problema dividiéndolo en subproblemas más pequeños y manejables.

Características principales

  1. Caso base: La función debe tener una condición que detenga la recursión (el caso base). Esto evita que la función se llame indefinidamente y cause un desbordamiento de pila (stack overflow).
  2. Caso recursivo: Es la parte de la función que llama a sí misma con un argumento modificado, acercándose al caso base.

Sintáxis básica en Python


def funcion_recursiva(parametro):
    # Caso base
    if condicion_para_detener: # ej: si n==1, entonces 
        return resultado       # devuelve n
    
    # Caso recursivo
    else:                      # si n!= 1 
        return funcion_recursiva(nuevo_parametro) # entonces se llama a si misma con un parámetro distinto (n-1) 
        

# definir la funcion recursiva
def funcion_recursiva(numero):
    # Caso Base
    if numero == 1:
        print(numero, end=' ')  # 1
    else: # Caso recursivo
        funcion_recursiva(numero - 1)
        print(numero, end=' ')

# Programa principal
funcion_recursiva(5)

Ejecución paso a paso

  1. Llamada inicial: funcion_recursiva(5)
    • La condición if numero == 1 no se cumple porque numero = 5.
    • Entonces, se ejecuta el caso recursivo: funcion_recursiva(4).
  2. Segunda llamada: funcion_recursiva(4)
    • La condición if numero == 1 no se cumple porque numero = 4.
    • Entonces, se ejecuta el caso recursivo: funcion_recursiva(3).
  3. () Quinta llamada: funcion_recursiva(1)
    • La condición if numero == 1 se cumple porque numero = 1.
    • Se imprime 1.
  4. Resolución de la recursión (regresando a cada llamada previa):
    • En la cuarta llamada (funcion_recursiva(2)), después de que se resuelve funcion_recursiva(1), se imprime 2.
    • En la tercera llamada (funcion_recursiva(3)), después de que se resuelve funcion_recursiva(2), se imprime 3.
    • En la segunda llamada (funcion_recursiva(4)), después de que se resuelve funcion_recursiva(3), se imprime 4.
    • En la primera llamada (funcion_recursiva(5)), después de que se resuelve funcion_recursiva(4), se imprime 5.

Visualización de la pila de llamadas

  1. Llamadas acumuladas (de arriba hacia abajo):
    2. 
funcion_recursiva(5)
funcion_recursiva(4)
funcion_recursiva(3)
funcion_recursiva(2)
funcion_recursiva(1)  # Caso base
  2. Resolviendo (de abajo hacia arriba):
    3. 
* funcion_recursiva(1) imprime 1.
* Regresa a funcion_recursiva(2), que imprime 2.
* Regresa a funcion_recursiva(3), que imprime 3.
* Regresa a funcion_recursiva(4), que imprime 4.
* Regresa a funcion_recursiva(5), que imprime 5.

"""
Esto ocurre porque en una función recursiva, cada llamada a la función se apila en la memoria 
(estructura de datos llamada pila de llamadas o call stack), y las llamadas se resuelven en 
orden inverso al que fueron realizadas. 
Esto es clave para entender por qué, después de alcanzar el caso base, 
se imprimen primero las operaciones de las llamadas más recientes.
"""
  3. Razón principal: LIFO (Last In, First Out)

    4. La pila de llamadas sigue un comportamiento de Último en entrar, primero en salir (LIFO): Cuando haces una llamada recursiva, esta se coloca "encima" de las llamadas previas en la pila. El caso base marca el punto donde se detienen las llamadas adicionales, y entonces la ejecución regresa desde la parte superior de la pila hacia abajo, resolviendo cada llamada pendiente. Esto ocurre porque el flujo de ejecución debe terminar las operaciones pendientes en cada nivel antes de pasar al nivel anterior. En el caso de esta función, la impresión ocurre después de que las llamadas recursivas han sido resueltas, lo que hace que los números se impriman en orden creciente.

Funciones recursivas pasando una lista y un diccionario como parámetro


# Función recursiva pasando una lista como parámetro

def funcion_recursiva(numero, lista):
    # Caso base
    if numero == 1:
        lista.append(numero)  # Agregar el valor 1 a la lista
    # Caso recursivo
    else:
        funcion_recursiva(numero - 1, lista)  # Llamar recursivamente con numero - 1
        lista.append(numero)  # Agregar el valor actual a la lista

# Programa principal
resultados = []  # Lista vacía para almacenar los resultados
funcion_recursiva(5, resultados)

print(resultados)
# Salida: [1, 2, 3, 4, 5]
        

# Función recursiva pasando un diccionario como parámetro

def funcion_recursiva(numero, diccionario):
    # Caso base
    if numero == 1:
        diccionario.update({numero: numero ** 2})  # Agregar clave y valor al diccionario
    # Caso recursivo
    else:
        funcion_recursiva(numero - 1, diccionario)  # Llamada recursiva
        diccionario[numero] = numero ** 2  # Agregar clave y valor al diccionario

# Programa principal
resultados = {}  # Diccionario vacío para almacenar los resultados
funcion_recursiva(5, resultados)

print(resultados)
# Salida: {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

"""
Pasar un diccionario como argumento:

Se pasa un diccionario vacío (resultados = {}) a la función.
Este diccionario se actualiza en cada llamada recursiva.
Agregar claves y valores al diccionario:

En el caso base, el número 1 se agrega como clave y su cuadrado como valor (diccionario[numero] = numero ** 2).
En el caso recursivo, después de completar la llamada a funcion_recursiva(numero - 1, diccionario), 
se agrega el valor correspondiente al número actual.
"""

Factorial de un número con recursividad

El factorial de un número entero positivo n (denotado como n!) se define en principio como el producto de todos los números enteros positivos desde 1 hasta n. Por definición, el factorial de 0 es 1.

Matemáticamente se expresa como: 

          n! = n.(n-1).(n-2).......1
Ejemplo:
          5!=5⋅4⋅3⋅2⋅1=120
          3! = 3⋅2⋅1 = 6
          0! =1 (por definición)
        


print('*** Factorial del Número 5 ***')

def factorial_recursiva(numero):
    if numero == 0 or numero == 1:
        print(f'Resultado factorial parcial {numero} es: 1')
        return 1
    else:
        factorial_parcial = numero * factorial_recursiva(numero - 1)
        print(f'Resultado factorial parcial {numero} es: {factorial_parcial}')
        return factorial_parcial

numero = 5
resultado = factorial_recursiva(numero)
print(f'El factorial de {numero} es: {resultado}')
Explicación del flujo
  1. Impresión inicial: El programa comienza mostrando el mensaje "Factorial del Número 5" para informar al usuario sobre la operación que realizará.
  2. Definición de la función: Se define factorial_recursiva, una función que calcula el factorial de un número utilizando recursión.
  3. Caso base: Si el número es 0 o 1, se imprime el resultado parcial (1) y se devuelve este valor.
  4. Caso recursivo:
    • Si el número es mayor que 1, se calcula el factorial parcial multiplicando el número actual por el resultado de llamar a la función con el número reducido en 1.
    • Cada paso imprime el resultado parcial antes de devolverlo.
  5. Ejecución de la función: Se inicializa el cálculo del factorial llamando a factorial_recursiva(5).
  6. Resultado final: Cuando la función recursiva termina, se imprime el resultado final: "El factorial de 5 es: 120".
